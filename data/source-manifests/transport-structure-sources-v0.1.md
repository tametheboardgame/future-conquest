# Transport structure sources v0.1

## Source hierarchy

1. European Commission TEN-T corridor and overview maps, Regulation (EU)
   2024/1679 network structure.
2. UNECE International E-road network map.
3. UNECE European Agreement on Main International Railway Lines (AGC).
4. Public general-geography references for named straits, passes and crossings.

## Method

The sources establish the existence and campaign importance of corridors. The
game data is an authored abstraction rather than a transcription of route
geometry. Coordinates mark places approximately for review rendering. Capacity,
vulnerability and repair turns are game-design values and must not be presented
as measured real-world performance.

## Durable versus dated data

Durable data includes the name, type, approximate location and territories
connected. Dated World State data will contain operational status, controller,
damage, restrictions and temporary capacity modifiers. This avoids rebuilding
the base map whenever a bridge closes or a new fixed link opens.
