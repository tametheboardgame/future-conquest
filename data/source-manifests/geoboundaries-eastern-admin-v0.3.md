# geoBoundaries eastern administrative source

- Dataset: geoBoundaries `gbOpen`
- Boundary level: ADM1
- Countries: Belarus (BLR), Moldova (MDA), Ukraine (UKR), Russia (RUS)
- Licence: CC BY 4.0
- Upstream repository: `wmgeolab/geoBoundaries`
- Retrieved: 2026-08-01
- Local source files are build inputs and are not committed.

The generated mapping CSV retains each source `shapeID` and its assigned campaign
territory. Administrative geometry is used only to construct playable regions;
political claims and current control are separate, dated World State data.
