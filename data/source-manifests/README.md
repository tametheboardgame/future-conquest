# Source Manifests

Every external dataset used by the project requires a manifest containing:

- source title and publisher;
- source URL;
- dataset version;
- retrieval date;
- licence and attribution requirements;
- original filename or release identifier;
- checksum where practical;
- transformations applied;
- generated outputs;
- update and replacement process.

Large third-party source files should not be committed automatically. The manifest should describe how an authorised copy is acquired and transformed.
