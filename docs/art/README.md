# Future Conquest visual design canon

This directory is the authoritative visual reference for Future Conquest artwork, motion-comic panels, character portraits, promotional art and later game-piece design.

## Authority order

1. `visual-design-bible-v1.md`
2. The approved reference sheets in `reference/`
3. `canon-generation-prompt-v1.md`
4. Scene-specific briefs and prompts

Where older concept art or prompts conflict with these files, this directory takes precedence.

## Approved reference sheets

- `reference/canon-armour-and-male-general.webp`
- `reference/canon-female-general.webp`
- `reference/canon-environments-and-portal.webp`

The environment sheet establishes atmosphere, portal behaviour and the future/present contrast. Exact place names, logos, markings and vehicle branding visible in generated reference art are illustrative and are not canon unless separately approved.

## Change control

A visual change is canon only when the design bible version is updated and the replacement reference is committed. Generated variations must not silently redefine armour geometry, the General, the portal, faction insignia or palette roles.
